# Quant Lab · DeepSeek Harness 量化研究助手

把交易想法转化为可核对的策略、历史回测与数字资产现货模拟盘。沿用 Harness 模型、登录和会话，使用专用预设工具、认证 RPC 与右侧量化工作台。

## 启动

Node.js `>=22.22.0`，Harness 依赖锁定为 `0.2.1-rc.3`。

```sh
npm run setup
npm start
```

新会话选择 **量化研究助手**，右侧打开 **量化工作台**。可先加载明确标注的合成数据，创建并发布策略，再完成第一次离线回测。模型需要在 Harness 中配置；数据和回测可直接操作工作台。

## 功能

- 均线交叉、区间突破模板；草稿修订与不可变发布版本。
- 公共历史行情、CSV 导入、连续性校验和不可变数据快照。
- 后台确定性回测、双边费用与滑点、仓位约束、逐笔交易与权益账本。
- 已收盘信号、公共行情驱动的本地模拟盘、暂停/恢复、决策日志。
- 回测比较、AI 复盘、JSON/CSV/Markdown 导出、完整备份和空目录恢复。
- 12 个预设领域工具；用户发布、资金与运行控制通过宿主认证 RPC 执行。

这是研究和模拟交易应用，不包含真实下单接口。电脑休眠或应用退出后不能继续监控。模拟盘重连与保护退出存在采样近似，详见使用说明。

## 开发验证

```sh
npm run check
npm run pack
```

`check` 执行类型检查、领域/账本/数据/权限/模拟事件与客户端异步测试、宿主和客户端构建，以及真实后台 worker 回测与客户端加载检查。真实模型质量和外部服务可用性需要另外验证，不由单元测试代替。
