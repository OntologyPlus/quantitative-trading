# Quant Lab · 持久量化研究 Agent

交付研究目标和预算，Agent 自动核对能力范围、准备数据、比较候选、验证最终区间并生成带证据的研究报告。研究状态持久保存，沿用 DeepSeek Harness 的模型、认证与会话。当前版本 `0.2.0`。

## 启动

Node.js `>=22.22.0`，Harness 依赖锁定为 `0.2.1-rc.5`。

```sh
npm run setup
npm start
```

新会话选择 **量化研究助手**，右侧打开 **量化工作台 → 研究委托**，填写目标，核对数据、门槛和预算后启动。Agent 模式使用 Harness 当前模型；也可选择明确标注的**固定协议模式**，无需模型完成整条自动研究流程。

离线体验：在首页下方“高级研究工具、示例与数据管理”加载合成示例，再在委托的数据选项中选中它。合成结果仅验证流程，不会被判定为市场有效性证据。

## 功能

- 持久研究项目、目标核对、事件续跑、项目级预算、暂停/取消/恢复和聊天归档联动。
- 均线交叉、区间突破、表达式策略与横截面轮动；12 个策略库起点、ATR/移动/时间止损与波动率仓位。仅现货多头，轮动暂不支持模拟盘。
- 开发/验证/最终保留区间，候选选择冻结、双倍成本检验和已揭示区间复用标记。
- 程序评估、逐字段证据核对、数字占位符填充、Markdown/JSON 研究交付与后续委托。
- 公共历史行情月度归档、CSV 导入、受限缺口容忍和不可变 JSON 快照；交易对目录提供带时间的缓存与分页。
- 后台确定性回测、双边费用与滑点、仓位约束、逐笔交易与权益账本。
- 已收盘信号、公共行情驱动的本地模拟盘、暂停/恢复、决策日志。
- 运行观察、异常与恢复通知去重、定期事实复盘、按需带入对话分析。
- 回测比较、JSON/CSV 导出、版本化完整备份、旧库迁移和空目录恢复。
- 研究实验室与聊天工具 `qt_lab_analyze`：绩效/成本报告、网格与随机扫描、DSR/PBO/Reality Check、滚动与锚定前推。扫描和前推仅支持单标的均线/突破与基础风控；尚未接入委托门槛。
- 聊天领域工具与专属研究执行工具分别作用域隔离；模拟运行需用户确认具体版本与配置。

这是研究和模拟交易应用，不包含真实下单接口。电脑休眠或应用退出后不能继续监控。模拟盘重连与保护退出存在采样近似，详见使用说明。

## 开发验证

```sh
npm run check
npm run check:optimizations
npm run check:launch
npm run check:browser
npm run benchmark:projects
npm run pack
```

`check` 包含类型检查、领域/调度/权限/预算/证据/恢复测试、真实 Harness Agent 循环集成、构建和六项真实 worker 实验的自动研究闭环。模型集成测试使用受控适配器，真实模型质量单独评测。`check:browser` 使用本机 Chrome；可通过 `QUANT_CHROME_PATH` 指定 Chromium 路径。

`check:optimizations` 在当前构建的隔离目录里，通过真实 Harness 工具和后台 worker 跑 SMA、EMA+ADX、扫描统计、前推与绩效报告，生成 `.runtime/optimization-verification.json`。只使用合成行情，不接触现有策略或账户。单独运行前先 `npm run build`。

常驻本地服务使用 `npm run start:server`。真实模型评测、公共行情长时间观察及部署说明见文档。
