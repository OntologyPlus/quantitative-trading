# 量化研究助手使用说明

## 启动

需要 Node.js 22.22.0 或更高版本。在本目录运行：

```sh
npm run setup
npm start
```

启动程序会检查源码与依赖配置指纹，必要时重新构建。默认绑定 `127.0.0.1`；在终端显示的 Harness 地址中打开应用。模型、登录和 API 配置沿用 Harness；本插件不内置密钥。

新会话选择「量化研究助手」，打开右侧「量化工作台」。Web 首次使用模型时，需要先在宿主中完成模型配置。数据和回测不依赖模型，可直接操作工作台。

## 第一次离线回测

1. 在「总览」点击「加载合成示例」。此数据用于验证流程，不能当作真实行情或策略业绩。
2. 在「策略」创建 BTCUSDT、1h 的均线交叉草稿，保存后点击「发布此版本」。
3. 进入「回测」，选择已发布策略及合成数据快照。
4. 展开实验配置，检查资金、权重、止损、止盈、敞口、损失限额、手续费与滑点。默认值只是实验配置。
5. 提交任务，等待后台计算。可切换页面，任务仍会执行。
6. 查看净值、回撤、逐笔成交、成本与基准；从「决策日志」核对每个信号与拒绝原因。可导出 JSON、CSV 和 Markdown。
7. 点击「请助手复盘」，检查插入对话的文字后发送；助手只能依据真实工具结果解释。

回测仅使用收盘数据生成信号，最早按下一根开盘加不利滑点模拟成交。开盘订单的成交量约束采用上一根已知成交量；保护性退出使用 K 线模型。根内路径未知时采用止损优先。期末持仓估值，不自动生成平仓交易。

## 使用真实历史数据

「数据」支持公共 Binance 行情下载，公共数据无需交易密钥。下载是持久任务，失败会显示明确原因，可改用本地 CSV。

CSV 格式如下，`time` 为 K 线开盘时间的 UTC 毫秒：

```csv
time,open,high,low,close,volume
1735689600000,100,102,99,101,10000
1735693200000,101,103,100,102,12000
```

按当前选择的交易对和周期导入。行必须按时间连续递增，OHLC 有效、数据已收盘。重复、缺口、乱序或非法数值会拒绝导入。单次最多一百万根，文件最多 64 MB。

数据快照不可变，记录来源、hash、规则快照时间。CSV 使用明确标注的默认交易规则；公共下载使用抓取时的交易规则。当前规则不一定等于历史规则，回测报告需按近似解读。固定交易对池不代表历史全市场选币。

## 策略与评估

首版提供均线交叉和区间突破模板。均线用相邻两根收盘指标判断交叉；突破区间排除当前 K 线。发布版本不可修改；复制为新草稿后重新发布，旧实验保留。

多交易对策略需要每个交易对各选一份相同周期的数据。回测使用所有快照共同覆盖的时间范围；每个交易对同一时间只允许一个持仓。资金按交易对名称的稳定顺序分配。

评估起点之前的数据只用于指标预热，不计入区间收益。按时间划分开发期和样本外区间；查看样本外结果后再修改参数，应使用新的未来区间继续验证。

Sharpe 以 UTC 日终权益的日收益计算，年化系数为 365，无风险利率为零；少于 30 个日收益时不计算。零方差、无平仓或没有亏损的比率使用空值，不能据此声称零风险。

## 模拟盘

先发布策略，在「模拟盘」检查完整资金和风险配置后创建账户，再明确点击「启动模拟盘」。同一时间最多一个活跃模拟账户。

启动会从公共行情同步指标预热、抓取当前交易规则，再订阅已收盘 K 线。信号后查询有效公开成交价，叠加成本生成虚拟成交。记录信号与观察时间；不回填已过去的开盘价。

保护性退出约每十秒检查一次公共成交价，属于抽样近似，不保证捕获所有根内触发。它与历史 K 线止损模型存在差异。模拟保护退出及用户明确平仓不使用成交量参与率约束；真实市场可成交性尚未建模。

- 「暂停」停止行情观察并撤销待成交意图，保留持仓。
- 「停止」停止调度并撤销意图，保留持仓。
- 「按当前行情模拟平仓」是独立操作，先暂停，再使用有效公共行情结算虚拟持仓。
- 网络短暂断开会退避重连；观察缺口、多次连接失败或行情长期不可用会暂停并说明原因。
- 退出、重启或电脑休眠后不能继续监控。重启后需手动恢复，补数据用于重建指标，不补记缺口成交。
- 「停止生成」只影响当前模型调用；持久下载、回测和已启动模拟盘需要各自的取消或停止按钮。

金额采用十进制计算。模拟成交、账本、决策与账户 checkpoint 同事务保存；账户余额和持仓可从独立事件表核对。同一数据目录仅允许一个运行实例。

## 导出、备份与恢复

回测支持完整 JSON、逐笔 CSV 和 Markdown 报告；完整 JSON 包含决策与账本。总览支持完整备份，包含业务对象与被引用数据快照，不含宿主登录和模型密钥。

备份前暂停模拟盘，等待或取消后台任务。在线 JSON 备份上限 64 MB；更大数据请完全退出后备份整个 `.quant-data` 目录。

恢复仅支持空数据目录，校验完整性、引用和账本后写入。恢复账户处于停止状态，不自动恢复后台任务。备份恢复量化业务，不恢复 Harness 对话日志。

开发数据在本项目 `.quant-data/`。安装版数据在 `$DSH_HOME/plugins-data/quant-assistant/`，两者不是同一库。非正常终止后若提示目录已有运行实例，请确认旧进程已退出，最多等待两分钟租约过期后再启动；不要删除正在运行实例的数据。

## 安装到已有 Harness

```sh
npm ci --ignore-scripts
npm run check
mkdir -p artifacts
npm run pack
./node_modules/.bin/dsh plugin --profile web add "$PWD/artifacts/quant-assistant-harness-plugin-0.1.0.tgz"
```

包名对应 npm 产物 `quant-assistant-harness-plugin-0.1.0.tgz`。Web 使用锁定的 `0.2.1-rc.3` 验证目标；Desktop 必须使用应用自带 `dsh`，并以其兼容版本实际安装验证。

## 能力边界

本产品不接真实订单接口、不使用交易密钥、不执行任意策略源码。支持现货多头和模板策略；暂不支持部分成交、订单簿撮合、做空、杠杆、合约、链上交易和云端全天候托管。

模型生成的内容是解释或待验证假设，不能写入成交、资金或风控通过结果。模型可以草拟策略并提交有界研究任务；发布、账户和运行控制只能由已认证用户入口操作。
