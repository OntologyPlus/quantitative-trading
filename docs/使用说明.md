# 量化研究助手使用说明

## 研究委托（0.2.0）

首页以研究项目为中心。创建委托时填写目标、交易对和周期，可采用默认的公共行情区间，或者在“数据、评估门槛与预算”选择已有快照。日期按 UTC 解释，至少需要 180 根已收盘且连续的 K 线，每个交易对选择一份相同周期、覆盖完整区间的数据。

“Agent 自主研究”使用 Harness 当前会话的模型选择，无法取得时使用宿主默认选择。模型首先核对目标是否能由现有模板完成，再在授权预算内比较候选、决定是否追加实验、解释结果和交付报告。模型配置不完整时会显示“需要处理”，可以配置后恢复；未授权额外的后台标题或上下文压缩调用。

“固定协议自动执行”无需模型：按预定候选、验证门槛与排序完成研究，报告明确标注未使用模型规划。首次离线体验可在“高级研究工具、示例与数据管理”加载合成数据，再选中该快照。合成数据不会生成“研究假设已获市场支持”的结论。

创建草稿后核对完整协议并点击“确认协议并启动研究”。默认预算为最多 12 个实验、20 次模型请求、每次最多 2,048 个输出 token、十万根数据、600 秒累计计算和 24 小时授权。模型输入与实际费用根据宿主报告记录，不承诺精确金额封顶；未报告的用量标为缺失。

研究区间按时间划分为 60% 开发、20% 验证、20% 最终保留区间。两个默认候选各做开发和验证，最终候选冻结后才执行保留区间与双倍成本检验，通常共六项实验。追加候选消耗独立预算，并保留其理由和已有实验。失败尝试同样消耗预算，恢复不会重置额度。重复研究已经揭示的最终区间会被标记，不能作为新的盲测通过模拟推进门槛。

研究报告包括结论、全部实验、评估原因、证据引用、AI 解释和限制。“证据不足”和“假设未通过”均为有效交付。报告关键数字来自程序计算；AI 在解释中引用数值时使用证据占位符，由程序填入。点击指标证据可核对 run、manifest、结果 hash 与区间，并导出 Markdown 或完整 JSON。

### 研究阅读与操作改进（2026-10-31）

新建委托可选择“比较两类策略”或“检验成本影响”填入可编辑目标；已有选中报告时可直接打开解释已有结果。生成前会检查日期对齐、已收盘区间、默认候选所需实验预算、数据量及所选快照的覆盖，提示合成数据和较短最终区间的解释限制。服务端仍进行完整协议校验。

委托详情展示本次实际研究范围、UTC 日期，以及同时用 bps 和百分比表达的手续费、滑点。手续费注明买卖分别收取；数据来源、快照身份、仓位及成交近似可展开核对。成本来自已冻结协议，不将反馈或示例中的数值用作实际费率。

报告先展示所选候选在验证期、最终保留区间与成本压力下的依据和反证，再展示“限制（引用时务必保留）”及基于现有评估原因生成的下一步。点击阶段卡会打开对应实验并核对收益证据；可将反证问题带入对话。新增 Markdown 报告保留相同的研究条件、反证、限制和下一步。历史报告正文和 hash 不自动重写。

暂停、模型故障、数据连接、预算或授权耗尽、未知执行结果会显示不同的操作说明。预算或授权无法通过原委托继续时，使用关联后续研究；执行结果未知时先核对记录，页面不会提供直接重发入口。普通补充问题仍可回答后继续。

后续委托沿用原资金与仓位风险、成交量参与率、成本压力倍数及高级预算配置；页面中修改的资金、费用、门槛与实验/请求预算覆盖对应值。新委托重新比较两类默认模板，仍需核对并确认启动；复用已揭示区间的记录继续保留。

### 稳健性研究

新建委托时勾选“启用稳健性研究”，在启动前核对成本倍率、参数邻域、滚动窗口与每类诊断最低通过率。默认设置为验证期 1.5/2/3 倍手续费与滑点、参数 ±20%、三个滚动窗口、每类至少 50% 满足原评估门槛。通过率只是用户确认的本次研究标准，不是盈利概率或统计显著性。

两个默认候选通常需要 20 项实验：四项开发/验证、三项成本情景、两项参数邻域、六项滚动训练、三项滚动验证及两项最终检验。启用时实验预算自动至少提高至 20；改变窗口数量后按页面提示核对预算。参数在合法边界裁剪并去重时，实际实验可少于保守预算。失败与重试同样计入预算，追加候选会预留剩余诊断与最终检验所需额度。

成本和参数实验使用已揭示的验证区间，供敏感性诊断。均线仅扰动慢周期，突破仅扰动入场回看周期；百分比取整且至少变动一单位。其他参数不变，实际数值见结果表，不把邻域结果冒充新的盲测。

滚动验证只使用研究开始前已冻结的初始候选池，排除根据后续验证证据追加的候选。在开发与验证区间内，前半段作为第一窗训练段，其余依窗口数连续分段；训练段逐窗扩展，每窗按训练门槛、训练收益、候选身份排序后检验下一段。测试段不重叠，训练截止早于测试开始，各窗独立初始化资金，所有窗口结束后才揭示最终保留区间，不拼接为可交易组合净值。

报告增加成本曲线、参数对照、滚动窗口表及最终区间的月度/交易对收益归因。月度按 UTC 月末权益差计算，包含未实现盈亏，精确边界时点计入前月；交易对盈亏包含交易现金流、费用与期末市值。最大盈利交易占比的分母是所有盈利平仓交易的净收益，排除亏损与未实现盈亏；没有盈利平仓时显示无样本。点击归因数值可核对 run、结果 hash 与程序派生字段。

启用稳健性协议后，各类诊断也参与最终研究判定。证据不足保持“证据不足”，失败不会通过改变门槛来交付成功结论。导出和备份包含这些结果；恢复及模拟批准前会重新核对窗口、版本、成本、证据与结论。旧委托没有该字段时继续执行原六项基础流程，历史报告不自动补跑或重写。

暂停研究会停止派发新动作，已经开始的计算可以结束并保留结果。取消研究会撤销可取消任务，迟到结果不继续推进。宿主重启默认暂停研究；勾选允许重启后继续时，仍须满足原授权与预算。无法核对的模型执行保留已消耗预算并要求处理，不自动重发。来源聊天归档会暂停关联研究。需要改变范围或增加资源时，可新建关联的后续委托，原记录保留。

满足评估门槛、且不含合成或重复盲测数据的报告，提供“确认此配置并创建模拟账户”。创建的账户绑定确切策略与配置，仍需在“模拟盘”明确启动。模拟盘中的“运行观察与复盘”会合并相同故障、更新恢复状态，并定期生成累计事实复盘；需要 AI 解读时可带入对话。

以下手动策略、数据和回测功能仍保留，适合高级操作。

## 启动

需要 Node.js 22.22.0 或更高版本。在本目录运行：

```sh
npm run setup
npm start
```

启动程序会检查源码与依赖配置指纹，必要时重新构建。默认绑定 `127.0.0.1`；在终端显示的 Harness 地址中打开应用。模型、登录和 API 配置沿用 Harness；本插件不内置密钥。

新会话选择「量化研究助手」，打开右侧「量化工作台」。Web 首次使用模型时，需要先在宿主中完成模型配置。数据和回测不依赖模型，可直接操作工作台。

## 第一次离线回测

1. 在「总览」点击「加载合成示例」。此数据用于验证流程，不能当作真实行情或策略业绩。
2. 在「策略」创建 BTCUSDT、1h 的均线交叉草稿，保存后点击「发布此版本」。
3. 进入「回测」，选择已发布策略及合成数据快照。
4. 展开实验配置，检查资金、权重、止损、止盈、敞口、损失限额、手续费与滑点。默认值只是实验配置。
5. 提交任务，等待后台计算。可切换页面，任务仍会执行。
6. 查看净值、回撤、逐笔成交、成本与基准；从「决策日志」核对每个信号与拒绝原因。可导出 JSON、CSV 和 Markdown。
7. 点击「请助手复盘」，检查插入对话的文字后发送；助手只能依据真实工具结果解释。

回测仅使用收盘数据生成信号，最早按下一根开盘加不利滑点模拟成交。开盘订单的成交量约束采用上一根已知成交量；保护性退出使用 K 线模型。根内路径未知时采用止损优先。期末持仓估值，不自动生成平仓交易。

## 使用真实历史数据

「数据」支持公共 Binance 行情下载，公共数据无需交易密钥。下载是持久任务，失败会显示明确原因，可改用本地 CSV。

CSV 格式如下，`time` 为 K 线开盘时间的 UTC 毫秒：

```csv
time,open,high,low,close,volume
1735689600000,100,102,99,101,10000
1735693200000,101,103,100,102,12000
```

按当前选择的交易对和周期导入。行必须按时间递增，OHLC 有效、数据已收盘。允许缺失不超过 1%、单个缺口不超过 72 小时的数据快照；缺口中原定开盘的信号作废，不补造成交。重复、乱序或非法数值仍拒绝导入；模拟盘预热仍要求连续。单次最多一百万根，文件最多 64 MB。

数据快照不可变，记录来源、hash、规则快照时间。CSV 使用明确标注的默认交易规则；公共下载使用抓取时的交易规则。当前规则不一定等于历史规则，回测报告需按近似解读。固定交易对池不代表历史全市场选币。

## 策略与评估

提供均线交叉、区间突破、表达式和横截面轮动模板，以及 12 个策略库起点。均线用相邻两根收盘指标判断交叉；突破区间排除当前 K 线；表达式与轮动只读已收盘指标。轮动暂不支持模拟盘，单策略最多十个标的。发布版本不可修改；复制为新草稿后重新发布，旧实验保留。

多交易对策略需要每个交易对各选一份相同周期的数据。回测使用所有快照共同覆盖的时间范围；每个交易对同一时间只允许一个持仓。资金按交易对名称的稳定顺序分配。

评估起点之前的数据只用于指标预热，不计入区间收益。按时间划分开发期和样本外区间；查看样本外结果后再修改参数，应使用新的未来区间继续验证。

Sharpe 以 UTC 日终权益的日收益计算，年化系数为 365，无风险利率为零；少于 30 个日收益时不计算。零方差、无平仓或没有亏损的比率使用空值，不能据此声称零风险。

## 模拟盘

### 观察事实、后续研究与版本替换

“运行观察与复盘”区分连接事件、已收盘数据/持仓报价和账本更新。无持仓时的账本估值更新不会被视为新的有效行情；首次启动或恢复会等待本轮数据，超过一个周期及缓冲仍没有收盘数据时标为过期。暂停、断线、重启和关闭期间的中断保留在记录中，恢复不会把累计缺口清零。

可按约定周期或点击“生成当前事实复盘”冻结累计账本、策略、资金风险配置、行情观察记录及原研究依据。冻结状态按内容hash存入 `results/`，新行情不会改写旧复盘；点击数值可核对复盘、快照与字段身份。旧版没有冻结快照的历史复盘继续可读，需要新证据时先生成当前复盘。

复盘将模拟累计事实与原研究最终保留区间并列展示，明确它们处于不同时间区间。复盘规则v1要求至少7天行情跨度、至少10笔平仓（原研究要求更高时采用更高要求）；只有口径相同且累计观察记录完整无缺口时，才提示频率比超出历史描述的0.5—2倍。规则只是调查提示，不是统计显著性或盈利概率；累计口径出现过缺口时不自动给出频率偏移判断。费用率来自模拟配置和账本，不是交易所实际收费。累计回撤超过原研究约定上限时提示复核，不自动改参或切换策略。

点击复盘中的“从此问题生成研究草稿”会保留来源账户、冻结复盘及其hash，并关联原研究（如果有）。草稿按当前已收盘数据区间和原配置准备待核对的研究委托，不自动下载、开始研究或改变模拟盘；已有用户授权与研究预算不会被悄悄扩大。

满足研究门槛的报告提供“核对模拟版本与运行变更”。可以创建独立账户，或选择替换已有观察账户；页面逐项展示策略、周期、参数、资金、风险、成本及引擎版本差异。替换前必须暂停/停止原账户、处理持仓和撤销待成交意图，再重新核对预览。原账户状态变化会使旧预览失效。

用户明确确认替换后，旧账户停止并保留账本、复盘和批准记录，不能再次恢复；新账户采用独立虚拟资金，不迁移原账户资金或持仓，并保持未启动，需在模拟盘再次明确启动。变更和批准记录随完整备份保存。资金、风险或成本与已验证研究不同时，先建立对应研究，不能直接套用原报告通过结论。

升级后如执行引擎指纹变化，已有账户和报告保留用于核对，原账户仍按既有规则禁止直接恢复。新模拟批准也会检查研究实验的引擎版本，需使用当前版本完成适用的新研究；不会自动重算旧报告或覆盖旧批准。

先发布策略，在「模拟盘」检查完整资金和风险配置后创建账户，再明确点击「启动模拟盘」。同一时间最多一个活跃模拟账户。

启动会从公共行情同步指标预热、抓取当前交易规则，再订阅已收盘 K 线。信号后查询有效公开成交价，叠加成本生成虚拟成交。记录信号与观察时间；不回填已过去的开盘价。

保护性退出约每十秒检查一次公共成交价，属于抽样近似，不保证捕获所有根内触发。它与历史 K 线止损模型存在差异。模拟保护退出及用户明确平仓不使用成交量参与率约束；真实市场可成交性尚未建模。

- 「暂停」停止行情观察并撤销待成交意图，保留持仓。
- 「停止」停止调度并撤销意图，保留持仓。
- 「按当前行情模拟平仓」是独立操作，先暂停，再使用有效公共行情结算虚拟持仓。
- 网络短暂断开会退避重连；观察缺口、多次连接失败或行情长期不可用会暂停并说明原因。
- 退出、重启或电脑休眠后不能继续监控。重启后需手动恢复，补数据用于重建指标，不补记缺口成交。
- 「停止生成」只影响当前模型调用；持久下载、回测和已启动模拟盘需要各自的取消或停止按钮。

金额采用十进制计算。模拟成交、账本、决策与账户 checkpoint 同事务保存；账户余额和持仓可从独立事件表核对。同一数据目录仅允许一个运行实例。

## 优化能力与统计分析

`qt_status.engineVersion` 是当前运行构建的引擎版本，`asOf` 只是状态读取时间。历史回测不会因升级重算；`qt_run_read` 返回 `usesCurrentEngine`、`computeMs` 及 `result.state.idle`（被省略的预热、无信号计数）。历史结果没有计数时返回 `null`，不推断为零。

在研究增强实验室或聊天的 `qt_lab_analyze` 中，使用当前引擎的已完成独立回测生成分析：

- `performance-report`：支持所有模板，返回 CAGR、Sortino、Calmar、回撤持续时间、滚动 Sharpe、年度/月度、市场状态与成本敏感性；需至少两个 UTC 日。
- `parameter-sweep`：单标的均线/突破的网格或随机搜索；DSR/PBO/Reality Check 位于 `statistics`，至少需要两个组合和三十个日收益，样本不足返回 `null`。
- `walk-forward`：单标的均线/突破的滚动或锚定窗口；设置 `trainBars`、`testBars` 和 `grid`。扫描和前推均不支持附加条件、表达式/轮动和高级风控。

例如 `qt_lab_analyze({action:"performance-report",input:{runId:"当前回测ID",costMultipliers:[0,1,2,3]},limit:50})`。返回源引擎版本、manifest/result 身份、合成数据标记及完整分析的 `analysisHash`。扫描行使用 `offset/limit` 分页，曲线只采样展示，数值统计基于完整数据。完整结果可在实验室导出。委托流程仍使用固定开发/验证/保留区间，实验室分析不自动变为项目通过证据；进行中委托须通过项目工具推进。

`qt_symbols` 返回 `{symbols,asOf,stale,source,total,offset,limit,hasMore}`，空 `query` 可分页浏览全目录。新鲜目录缓存五分钟；查询失败时只读核对可回退到不超过一天的旧目录并标记 `stale:true`，执行准备不使用过期缓存。草稿只校验语法，保存成功不代表标的和数据已验证。数据详情 `quality` 另外返回缺失根数、最长缺口、缺失比例和处理规则；旧快照与其 hash 保持原样。

## 导出、备份与恢复

回测支持完整 JSON、逐笔 CSV 和 Markdown 报告；完整 JSON 包含决策与账本。总览支持完整备份，包含业务对象与被引用数据快照，不含宿主登录和模型密钥。

备份前暂停模拟盘，等待或取消后台任务。在线 JSON 备份上限 64 MB；更大数据请完全退出后备份整个 `.quant-data` 目录。

恢复仅支持空数据目录，校验完整性、引用和账本后写入。恢复账户处于停止状态，不自动恢复后台任务。备份恢复量化业务，不恢复 Harness 对话日志。

开发数据在本项目 `.quant-data/`。安装版数据在 `$DSH_HOME/plugins-data/quant-assistant/`，两者不是同一库。非正常终止后若提示目录已有运行实例，请确认旧进程已退出，最多等待两分钟租约过期后再启动；不要删除正在运行实例的数据。

## 能力边界

本产品不接真实订单接口、不使用交易密钥、不执行任意策略源码。支持现货多头和模板策略；暂不支持部分成交、订单簿撮合、做空、杠杆、合约、链上交易和云端全天候托管。

模型生成的内容是解释或待验证假设，不能写入成交、资金或风控通过结果。模型可以草拟策略并提交有界研究任务；发布、账户和运行控制只能由已认证用户入口操作。
