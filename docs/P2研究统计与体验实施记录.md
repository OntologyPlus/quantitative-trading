# P2 研究统计与体验实施记录

引擎版本不变（`quant-engine-0.3.0`），回测结果不受影响。新增内容全部在研究实验室中提供，并配有可视化结果。

## 新能力

| 项 | 内容 |
| --- | --- |
| 选择偏差统计 | `src/research/stats.ts`：概率 Sharpe（PSR）、紧缩 Sharpe（DSR，按试验次数和 Sharpe 离散度估计运气上限）、组合对称交叉验证的过拟合概率（PBO/CSCV）、White Reality Check（平稳自助法，固定种子可复现）。 |
| 参数扫描增强 | 扫描结果新增 `statistics`：对选中参数给出 DSR/PSR，对全部参数给出 PBO 与以现金为基准的 Reality Check p 值。新增随机搜索（`search: {mode: "random", samples, seed}`），同种子结果相同。 |
| 滚动前推 | 新实验室工具 `walk-forward`：滚动或锚定窗口，训练窗口用筛选内核选参，紧随其后的测试窗口用精确引擎回测；测试窗口互不重叠并拼接成样本外净值。报告样本外收益/年化/回撤/Sharpe、前推效率、参数变化次数，以及源参数在同一区间的静态对照。 |
| 绩效报告 | 新实验室工具 `performance-report`：CAGR、Sortino、Calmar、最长回撤与当前水下天数、偏度峰度、PSR、滚动 Sharpe、年度与月度收益、交易统计（胜率、盈亏、期望、持有时长、最长连亏、退出原因）、按等权篮子划分的上涨/下跌/震荡表现、成本 ×0/×1/×2/×3 精确重跑与盈亏平衡倍数。适用于所有模板，包括表达式和轮动。 |
| 界面 | `src/client/lab-results.tsx`：参数平面热力图、选择偏差指标卡、精确确认表；前推样本外曲线与窗口表；绩效指标卡、净值与滚动 Sharpe 曲线、月度收益热力表、交易/状态/成本表。完整 JSON 折叠在下方。实验室会自动带入当前选中的回测。 |

## 验证

`tests/research-p2.test.ts`：
- 正态函数精度；试验次数越多 DSR 越低。
- 纯噪声矩阵 PBO 在 0.2–0.8 之间、Reality Check 不显著；植入持续优势后 PBO < 0.1、p < 0.05；自助法可复现。
- 扫描统计取值范围、随机搜索可复现、行数据不泄露日序列。
- 前推：测试窗口首尾相接、训练窗口紧邻测试窗口；每个窗口结果可由精确引擎复现；拼接收益等于窗口收益连乘；改动第 k 个测试窗口的数据不改变第 k 个窗口选中的参数。
- 绩效：总收益与回测一致；成本 ×1 的结果 hash 与原回测相同；年度、月度收益连乘等于总收益；完整交易数等于平仓数。
- 三个可视化视图用真实结果渲染。

全部原有可运行测试通过。
