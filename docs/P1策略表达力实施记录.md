# P1 策略表达力实施记录

引擎版本升至 `quant-engine-0.3.0`。原有均线/突破模板的成交、账本与指标保持逐字节不变（`tests/engine-golden.test.ts`）。

## 新能力

| 项 | 内容 |
| --- | --- |
| 表达式语言 | `src/domain/dsl.ts`。安全的类型化表达式，不执行代码：`cross_above(ema(close, 12), ema(close, 26)) and adx(14) > 25`。支持 `+ − × ÷`、比较、`and/or/not` 与 29 个函数：sma ema wma rsi atr natr adx plus_di minus_di highest lowest stdev zscore bb_mid bb_upper bb_lower macd macd_signal macd_hist roc rvol vwap lag abs min max cross_above cross_below rising falling。保存时校验并给出出错位置。 |
| 表达式策略 | `template: "expr"`，`rules: { version: 1, entry, exit }`。退出优先于入场；指标只读已收盘 K 线。 |
| 横截面轮动 | `template: "rotation"`，`rotation: { version: 1, score, filter?, top, every }`。每 `every` 根按得分排序持有前 `top` 个；同一开盘先卖后买；每次调仓记录 `ROTATION` 决策和完整排名。 |
| 止损与仓位 | 风控新增可选项：`stopAtr`/`atrPeriod`（ATR 止损），`trailingStopPct`（最高价回撤移动止损），`trailingAtr`（吊灯止损），`maxHoldBars`（时间止损），`sizing: "volatility"` + `targetVolPct`/`volPeriod`（目标波动率定仓）。移动止损只收紧不放松。 |
| 策略库 | `src/domain/strategy-catalog.ts`，12 个公开策略族起点：双均线、海龟、EMA+ADX、MACD、RSI 回归、布林回归、Z 分数回归、布林突破、波动收缩突破、时间序列动量、横截面动量轮动、低波轮动。参数为教科书默认值，未经验证。 |
| 接入 | 工作台策略页可选表达式/轮动、从策略库填入、填写高级止损；`qt_strategy_read` 返回函数说明、风控选项与策略库；Agent 与助手提示词已更新；稳健性检验对表达式按比例平移所有周期。 |

## 数值约定

指标用 float64 计算，只用加减乘除和开方（IEEE 正确舍入），同一输入在任何机器上结果一致。成交、资金、账本仍用十进制精确计算。EMA 用首个窗口的 SMA 作为种子，RSI/ATR/ADX 用 Wilder 平滑，预热长度分别取 4 倍、4 倍、8 倍周期。

## 验证

- `tests/dsl.test.ts`：语法、规范化输出、错误信息；各指标与独立参考实现逐值一致；交叉只看上一根与本根。
- `tests/strategy-p1.test.ts`：表达式重写的均线/突破与内置模板逐笔一致；12 个策略库条目全部可校验、回测、对账且结果确定；轮动的排名、调仓节奏、先卖后买与无未来函数；ATR/移动/吊灯/时间止损与波动率仓位；表达式的稳健性邻近参数。
- 全部原有可运行测试通过。

## 限制

- 未实现做空、杠杆与永续合约（含资金费率）：需要重做账本与持仓模型，单独排期。
- 轮动策略只支持回测，模拟盘会拒绝（需要多标的同步行情）。
- 参数扫描仍只支持均线/突破模板与基础风控。
- 表达式策略回测比模板慢：10 万根 1m 约 4–5 秒（模板约 1.6 秒），因为每根 K 线重算保留窗口内的指标序列。
