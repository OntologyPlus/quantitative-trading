# 模拟观察闭环实施记录

日期：2026-10-31。范围：整体改进方案第三阶段，承接前两阶段工作区改动。

## 本轮实现

| 能力 | 行为与边界 |
| --- | --- |
| 行情健康 | 分开记录连接、有效行情、已收盘K线与账本更新时间；有持仓时核对报价新鲜度；启动/恢复等待本轮数据，长期没有收盘数据时不能被连接心跳掩盖 |
| 中断记录 | 暂停、断线、故障、关闭、重启和替换持久留痕；恢复保留累计次数和时长；升级前记录不足保持未知 |
| 冻结事实复盘 | 手动或定期将账本、配置、原研究与观察事件冻结，状态以hash产物保存；逐字段证据可读取、重算核对，旧复盘不随账户变化 |
| 描述性偏差 | 比较样本、交易频率、成本口径、回撤假设与观察缺口；不同区间收益不直接判为策略失效；样本不足、口径变化或累计缺口时不作频率偏移推断 |
| 关联后续研究 | 根据保留的问题生成待确认草稿，绑定来源复盘hash与账户，关联原研究；不自动启动或改变运行参数 |
| 变更预览 | 对比策略、市场、周期、参数、资金、风险、成本和引擎版本，预览hash绑定确切源账户状态与目标研究 |
| 用户批准替换 | 运行中、持仓未处理、意图未撤销、预览过期或研究口径不匹配时拒绝；确认后原账户停用且保留，新账户独立资金并保持未启动 |
| 备份与兼容 | 完整备份包含行情事件、观察状态、冻结快照、复盘、关联研究及变更批准；恢复前核对引用、hash、账本和派生值，恢复不启动任务 |

复盘规则v1采用7天行情跨度、至少10笔平仓（不低于原研究样本门槛）和0.5—2倍描述性频率比。这是明确展示的调查规则，不是通用交易建议、盈利概率或显著性检验。

## 使用与交付范围

从“模拟盘 → 运行观察与复盘”生成事实复盘并创建研究草稿；新研究通过后，在报告的版本与运行变更面板核对、确认。新账户必须由用户单独启动。

本次修改涉及模拟执行文件，因此会改变当前构建的引擎指纹。旧账户不能绕过既有引擎检查直接恢复，旧研究也不能直接为不同引擎的新运行背书；历史记录保留，需要按当前版本完成适用的研究并重新确认。

未实现同一实时时段的独立行情重放、真实订单、自动切换参数、新策略模板或托管全天候运行。七日真实公共行情观察、真实模型质量评测、目标用户试用与Desktop安装验证仍未完成；受控数据和虚拟时钟测试不能代替这些门槛。
