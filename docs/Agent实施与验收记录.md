## 与规划的具体实现选择

- 初始候选与时间切分由用户确认的结构化协议冻结。Agent 先核对能力，再根据证据决定是否追加候选，最终选择只提交一次。
- 单机使用 SQLite 业务对象保存项目快照，关系表保存版本化项目事件与消费游标。阶段、实验依赖、派发和预算在事务中持久化。
- 大回测结果写入 `results/` 的不可变 hash 文件。列表读取摘要；显式打开和导出时校验并恢复完整结果。
- SQLite 和宿主日志无法原子提交，投递采用至少一次语义。模型执行无法核对时保留预算并要求处理，不宣称跨存储“恰好一次”。
- 输出 token 与请求次数有程序上限，输入及缓存输入按宿主报告记录。额外标题和上下文压缩模型调用未获授权，专属执行会话会拒绝；不显示精确金额封顶。
- AI 解释采用定性文字和数值证据占位符，数值由程序填入；解释语义质量仍需真实模型评测。
- 持续模拟交付确定性观察与周期事实复盘；AI 解读按用户带入对话触发，没有在未取得独立预算时自动持续调用模型。
